# ТЗ: своя кривая ОФЗ на вкладке ОФЗ (`/fixed/ofz`)

Дата: 2026-09-15. Ветка `floaters-desk-deploy`.
Файлы: `frontend-react/src/components/fixed/OfzDesk.jsx`, `OfzChart.jsx`,
`fixedCols.jsx`, `api/routes/fixed.py`, новый `services/ofz_curve.py`,
`services/portfolio_db.py` (таблица архива), `frontend-react/src/api.js`.

## Суть

Линия КБД МосБиржи с графика УБИРАЕТСЯ. Вместо неё — **своя кривая ОФЗ**,
подогнанная по точкам самих выпусков (YTM × дюрация Маколея), которые уже
лежат на графике. Отклонение точки на графике и в таблице — к НАШЕЙ кривой.

Что НЕ меняется:
- Движок фиксов (`services/fixed_income`) и колонка G-SPRD в мониторе — как
  были (к КБД). Ручка `/api/curves/gcurve` и архив `gcurve_daily` остаются:
  ими пользуется движок и другие места. Из OfzDesk их вызов убираем.
- Правило страницы: **в браузере ничего не считается**. Подгонка — на бэке,
  фронт рисует `samples` и берёт готовые остатки по ISIN.

## Бэкенд

### `services/ofz_curve.py` — подгонка (только numpy, БЕЗ scipy: его нет в
requirements, а прод живёт в 768 МиБ)

Модель Нельсона–Сигела–Свенссона по оси τ = дюрация Маколея (лет):

```
y(τ) = β0 + β1·f1(τ,λ1) + β2·f2(τ,λ1) + β3·f2(τ,λ2)
f1(τ,λ) = (1−e^{−τ/λ})/(τ/λ);  f2(τ,λ) = f1(τ,λ) − e^{−τ/λ}
```

- При фиксированных (λ1, λ2) β — взвешенный линейный МНК (`numpy.linalg.lstsq`).
  Перебор λ по сетке: λ1 ∈ logspace(0.3 … 6, 24 точки), λ2 ∈ logspace(2 … 25,
  16 точек), λ2 ≥ 1.5·λ1. Минимум взвешенной суммы квадратов.
- Робастность: 3 итерации IRLS с весами Хьюбера (c = 1.5·σ_robust, σ_robust =
  1.4826·MAD остатков), нижняя граница веса 0.1. Одна дорогая/дешёвая бумага не
  должна тащить кривую.
- Фолбэк на NS (β3 = 0, одна λ) если использовано < 8 точек ИЛИ NSS улучшает
  RMSE менее чем на 5 % относительно NS (лишний параметр не оправдан).
- Стартовые веса точек: `w = clip(0.25 + log10(1 + оборот_дня_руб/1e6)/2, 0.25, 2)`
  — неликвид считается, но не рулит. Для баз bid/ask — та же формула (оборот
  = мера надёжности котировки).
- Исключения из подгонки (`used=false`, остаток всё равно считаем): τ < 0.25,
  YTM отсутствует/вне [0, 40] %, τ отсутствует. Минимум для подгонки — 4
  точки, иначе ручка отдаёт 422 с текстом.
- Выход `FitResult`: `method` ("NSS"|"NS"), `params` (β0..β3, λ1, λ2),
  `n_used`, `n_total`, `rmse_bps` (по использованным), `domain` [τmin, τmax],
  `samples` — τ от 0.1 до τmax+0.5 шагом 0.05 (`[{years, yield_pct}]`, 4 знака),
  `key_tenors` — τ ∈ {0.5, 1, 2, 3, 5, 7, 10, 15} с флагом `extrap` (вне
  domain), `residuals` — `{isin: {bps, weight, used}}`, bps = (ytm − y(τ))·100.
- Функция `evaluate(params, tau)` — для будущих потребителей (аукционы:
  премия к кривой).
- Чистые функции, тестируемые без сети: `tests/test_ofz_curve.py` — синтетика
  NSS восстанавливается с RMSE < 1 бп; один выброс +150 бп не сдвигает кривую
  в его теноре больше чем на 15 бп; n<4 → исключение; NS-фолбэк срабатывает
  на 6 точках.

### Ручка `GET /api/fixed/ofz/curve?base=wap|last|bid|ask&date=YYYY-MM-DD`
(в `api/routes/fixed.py`, рядом с `/ofz/asof`)

- Без `date`: точки из `_ofz_rows()` + кэш метрик (те же строки, что `/api/fixed`
  с `cls=ofz`). YTM по базе — та же карта, что `byBase` во фронте:
  wap→`ytm_wap`, last→`ytm`, bid→`ytm_bid`, ask→`ytm_ask`; τ = `mac_dur`
  (фолбэк `mod_dur`); оборот — `val_today` (или как в `/ofz/volumes`).
- С `date`: точки из логики `get_ofz_asof(date)` (ytm, tau, px) — база одна
  (as-of цена), в ответе `base: "asof"`; `date`/`requested`/`stale` — как у
  `/ofz/asof` (шаг назад до 7 дней). Вынести общий код as-of в функцию,
  чтобы обе ручки его делили, не копировать.
- Ответ: `{date, requested, stale, base, method, n_used, n_total, rmse_bps,
  params, domain, samples, key_tenors, residuals}`.
- Мемо в памяти: ключ (base, date, отпечаток входа = хэш отсортированных
  (isin, round(ytm,4), round(tau,3))), TTL 60 с для «сегодня», as-of — как у
  `_asof_memo`. Правило проекта: отпечаток ВСЕГО входа в ключе кэша.
- Архив: таблица `ofz_curve_daily(date TEXT, base TEXT, method TEXT,
  params TEXT/json, rmse_bps REAL, n_used INTEGER, at TEXT, PRIMARY KEY(date, base))`
  в `services/portfolio_db.py` (CREATE TABLE IF NOT EXISTS в общей схеме).
  Пишется при каждом расчёте «сегодня» (upsert, последний побеждает) — копится
  история своей кривой для аналитики (аукционы, динамика теноров).

## Фронт

- `api.js`: `fetchOfzCurve(base, date)`.
- `OfzDesk.jsx`: `curveQ` → `fetchOfzCurve(base)` (ключ `["ofzCurve", base]`,
  refetch 60 с — сегодняшняя кривая ходит с ценами); `curveCmpQ` →
  `fetchOfzCurve(null, cmpDate)`. Убрать `fetchGCurve`, `curveAt(ytm, g)`.
  `curve` точки = `ytm − residuals[isin].bps/100`; в точку добавить
  `resid` (бп) и `used`.
  Шапка: вместо «КБД от …/кривая не сегодняшняя» — «кривая ОФЗ: NSS по
  N из M выпусков, RMSE X бп» и при `stale` as-of — фактическая дата.
  Комментарий-шапку файла переписать: смысл страницы теперь — отклонение от
  СВОЕЙ кривой; КБД со страницы ушла.
- `OfzChart.jsx`: линия — `samples`; `curveDelta`/`CurveDeltaStrip` — по
  `key_tenors` обоих ответов (совпадающие теноры, `extrap` не показываем),
  подпись «Δ кривая ОФЗ». Тултип точки: «YTM · кривая · откл. ±N бп». Подписи
  точек — отклонение к своей кривой. Точки с `used=false` — полый кружок,
  в тултипе «вне подгонки». Все упоминания «КБД» в тексте страницы/тултипов
  заменить на «кривая ОФЗ».
- `fixedCols.jsx` `OFZ_EXTRA_COLS`: колонка `Δ КРИВАЯ` («К СВОЕЙ, БП»,
  `b.resid_bps`, знак/цвет как у ΔYTM, сортируемая). G-SPRD (движок, к КБД)
  в общих колонках не трогать.
- Тесты: обновить `OfzChart.test.jsx` (ожидания по тексту «КБД» → новая
  подпись, `key_tenors` в delta), добавить кейс «used=false рисуется
  полым». `npx vitest run` в `frontend-react` зелёный.
